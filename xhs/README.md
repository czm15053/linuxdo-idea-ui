# 小红书 · IM 三合一伪装外观（xhs-im.user.js）

一套油猴脚本，将 [xiaohongshu.com](https://www.xiaohongshu.com/) 网页版深度伪装成 **钉钉 PC 端**、**飞书 IM** 或 **企业微信** 办公聊天界面。

**只换皮，不碰隐私与凭证**：笔记自动投影为聊天消息气泡，点赞、收藏、关注全部走官方原生前端 Vue 运行时触发，免逆向、免签名、零风控风险。

---

## 核心功能

### 1. 三合一风格秒切（钉钉 / 飞书 / 企业微信）
* 一套脚本集成三款主流办公协同界面，随时一键切换，偏好自动本地记忆；
* 官方风格图标与调色板，自动跟随系统深浅色模式。

### 2. 笔记流式聊天化阅读
* 信息流（发现推荐、搜索结果）自动排版为日常聊天气泡，清晰展示作者、发布时间、标题与封面；
* 触底自动加载下一批笔记，右上角刷新或再次点击「发现推荐」即可换一批；
* 侧边栏常驻假会话填充，融入办公环境不穿帮。

### 3. 右侧详情抽屉与多级评论区
* 点击笔记从中栏右侧平滑抽出详情抽屉，展示完整笔记长文、图组与多级评论树；
* 阅读详情时主列表阅读进度完全冻结，关闭抽屉即可回到原本阅读进度，不跳路由、不白屏。

### 4. 摸鱼护栏与防社死机制
* **纯文本摸鱼模式**：一键隐藏所有图片与视频；
* **防窥脱敏模式**：一键将博主头像打散为百家姓单字头像，标题与群名伪装为日常工作项目沟通组；
* **标签页伪装**：Favicon 与浏览器标题自动锁定为对应办公软件（如 `企业微信`、`钉钉 - 工作台`、`飞书`）。

### 5. 完整社交互动
* 聊天气泡与详情抽屉下方快捷栏一键点赞、收藏；
* 支持关注/取消关注博主；
* 点击博主头像或昵称可查看其个人主页名片与全部公开笔记。

---

## 安装使用

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）或 Violentmonkey 扩展；
2. 打开当前目录下的 [`xhs-im.user.js`](./xhs-im.user.js)，点击 **Raw** 进行安装；
3. 访问 <https://www.xiaohongshu.com/> 即可自动生效（初次安装后请硬刷新一次页面 `Ctrl+F5` 或 `Cmd+Shift+R`）。

---

## 本地开发与构建

本子模块为**完全独立自包含的 Vite 工程**，与上游其它站点完全解耦：

```bash
cd xhs

# 安装依赖
pnpm install

# 实时监听开发（改动即编译）
pnpm dev

# 代码检查与生产打包（产物自动输出至 xhs-im.user.js 及 dist/xhs-im.user.js）
pnpm lint
pnpm build
```
