Hooks 的正确打开方式

很多人把 hooks 当装饰用，其实它是唯一能确定性地约束 agent 行为的手段。常用三类：

  • PreToolUse：拦截危险命令，比如 rm -rf、裸 git push
  • PostToolUse：写文件后自动跑 prettier --write
  • Stop：收尾时强制跑一遍测试，红了就不让停

配置放在 settings.json (hooks 字段)，参考官方文档 Claude Code Hooks。

json — ~/.claude/settings.json 复制 
"hooks": {
  "PostToolUse": [{
    "matcher": "Edit|Write",
    "hooks": [{ "type": "command", "command": "pnpm lint --fix" }]
  }]
}

补充一个坑：Stop hook 里跑测试记得加超时，不然 agent 会被一个挂起的 watcher 卡死。我一般用 timeout 120 pnpm test 包一层。

subagent 上下文隔离

子代理最大的价值不是并行，是上下文隔离——搜一万行代码，主上下文只带回来十行结论。原则：

  1. 探索类任务全走子代理，主线程只做决策
  2. 子代理 prompt 里写死路径，别让它自己找
